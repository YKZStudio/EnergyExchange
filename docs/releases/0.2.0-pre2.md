# 0.2.0-pre2

## English

- Replace the full cube with an original low stone transmutation plate, teal/brass alchemy markings and a matching portable icon. No enchanting-table model or ProjectE assets are used.
- Remove the separate learning button. Convert all consumes the full valid input stack, credits Energy and learns automatically.
- Default to learned items; optional All view keeps learned entries first. Add empty-state guidance and separate purchase, XP, pagination and inventory areas.
- Buy 64 / 32 / 16 / 1; disable quantities above the stack limit or available balance. The server independently rejects oversized/nonstandard UI purchase counts.
- Add experimental, default-off pinyin search in Mod Menu: full spelling, initials and mixed syllable prefixes, without requiring REI.
- Use English default documentation with `_zh-CN.md` companions. Localize in-game mod names and all messages into English, Simplified Chinese, Japanese, German, French, Spanish, Brazilian Portuguese and Russian.
- Correct underpriced rare-material anchors and solve self-referencing recipe constraints algebraically. Existing balances/knowledge are retained; default prices change. Data-pack overrides retain priority.
- Migrate pre1 settings while keeping XP and number preferences; initialize learned-only browsing and disabled pinyin.
- Add pinyin/quantity tests, real-client pearl purchase and forged-request checks, and wait for resource loading before Chinese screenshots.

Requires Minecraft 26.2, Java 25, Fabric Loader 0.19.5+ and Fabric API 0.159.0+26.2 on both sides. Use matching pre2 versions on client and server. Some polyphonic readings, third-party gun-pack economies and unusual GUI scales still need player feedback.

## 简体中文

- 转化桌改为原创低矮石盘，配青绿、黄铜色炼金纹路和同风格便携图标，不使用附魔台模型或 ProjectE 素材。
- 删除单独学习按钮；「全部转化」消耗槽内整组有效物品，获得能量并自动学习。
- 默认仅显示已学物品，可切换全部且已学优先；增加空列表指引，分开购买、经验、翻页和背包区域。
- 购买数量改为 64／32／16／1；超堆叠上限或余额不足时禁用，服务端独立拒绝非法界面购买数量。
- Mod Menu 新增默认关闭的实验性拼音搜索：支持全拼、首字母和混合音节前缀，无需 REI。
- 文档默认英文，中文使用 `_zh-CN.md`；游戏内名称与全部文字支持中、英、日、德、法、西、葡、俄。
- 修正稀有材料过低定价，以代数方式处理自引用配方。保留已有余额和知识，默认价格有所调整，数据包覆盖仍优先。
- 迁移 pre1 设置，保留经验与数字偏好，初始化为仅已学目录及关闭拼音。
- 增加拼音／数量测试、真实客户端末影珍珠购买与伪造请求检查，修正中文截图早于资源加载完成的问题。

双端要求 Minecraft 26.2、Java 25、Fabric Loader 0.19.5+、Fabric API 0.159.0+26.2，并使用相同 pre2 版本。部分多音字、第三方枪包经济及特殊 GUI 缩放仍需要玩家反馈。
