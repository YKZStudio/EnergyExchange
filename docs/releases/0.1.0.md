# Energy Exchange 0.1.0 / 能量交换 0.1.0

## 简体中文

首个基础逻辑版本，适用于 Minecraft Java 26.2 + Fabric。

- 使用 `/ee` 命令分解普通物品、获得个人能量、学习并兑换物品。
- 分解自动学习；单独学习消耗一个样本；默认包含 20 种基础资源价格。
- 128 位十进制精确整数上限、服务端验证和背包容量整笔预检。
- 玩家账户持久化、死亡保留、损坏存档锁定保护。
- 数据包覆盖及禁用物品规则，支持 `/reload`；严格解析 JSON，重载失败禁止交易。
- 简体中文/英文游戏文字、使用说明、开发文档和数据包示例。
- 构建、JUnit 单元测试和 7 项服务端游戏测试通过。

安装：Java 25、Fabric Loader 0.19.5+、Fabric API 0.159.0+26.2。将发行版 JAR 放入 `mods` 文件夹。此版本为命令入口，不包含图形界面和转化桌；客户端人工验收清单见开发文档。

## English

The first core release for Minecraft Java 26.2 + Fabric.

- `/ee` commands burn default items into personal Energy, learn items and buy them back.
- Burning learns automatically; separate learning consumes one sample. Includes 20 starter resource values.
- Exact arithmetic up to 128 decimal digits, server validation and all-or-nothing inventory preflight.
- Persistent player accounts retained after death; corrupt saves lock trading and preserve original data.
- Data-pack overrides and disabled rules with `/reload`; strict JSON and fail-closed reload handling.
- English/Simplified Chinese game text, user/developer documentation and example data packs.
- Build, JUnit unit tests and all 7 required server GameTests passed.

Requires Java 25, Fabric Loader 0.19.5+ and Fabric API 0.159.0+26.2. Install the release JAR in `mods`. This release uses commands and does not include a GUI or transmutation table. See developer documentation for the manual client acceptance checklist.
