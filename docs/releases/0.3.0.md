# Energy Exchange 0.3.0

## English

- Add 32 materials, weapons, tools and armor inspired by ProjectE/Avaritia: Dark Matter, Red Matter, Infinity, the Red Matter Katar and Morning Star, Crystal Matrix, Neutronium and Infinity crafting materials.
- Every recipe fits the vanilla 3×3 table, with recipe-book unlocks. New gear has explicit recipe-constrained Energy in vanilla, TaCZ, Traveler’s Backpack and combined profiles.
- Unbreakable gear; right-click area mining at 3×3/5×5/7×7; hostile-mob sweeps; full-suit bonuses culminating in Infinity flight, regeneration, food and ordinary damage protection. Unequipping revokes owned flight and gives a brief safe landing window.
- Area mining honors vanilla/Fabric protection, skips containers and unbreakable blocks, never loads chunks and checks at most 49 blocks. Area attacks exclude players and pets. Void and `/kill` remain effective.
- F3+H advanced tooltips show `ENERGY <exact value>` immediately above the item ID. Public prices synchronize from the server on join/reload; private balances and knowledge are not shared. `—` denotes no available price.
- Retain MIT-licensed ProjectE/Re-Avaritia item/armor textures and animations, with bundled notices and provenance. Use vanilla equipment rendering; no custom cosmic shader or wings.
- Update all ten locales and English/Simplified Chinese documentation, including the complete recipe/control guide.

Requires Minecraft 26.2, Java 25 and the Fabric dependencies listed in the README. Existing accounts/settings are preserved. As in 0.2.1, conversion discards enchantments, container contents and other sample data; purchases return default items. See `docs/ARMORY.md` for controls and implementation differences.

## 简体中文

- 新增 32 个参考 ProjectE／无尽贪婪的材料、武器、工具与盔甲：暗物质、红物质、无尽装备，红物质拳剑／钉头锤，以及水晶矩阵、中子与无尽合成材料。
- 所有配方使用原版 3×3 工作台，支持配方书解锁。新装备在原版、TaCZ、旅行者背包及组合定价中均有按配方约束的能量价值。
- 装备无耐久损耗，工具右键 3×3／5×5／7×7 范围采掘，武器范围攻击敌对生物；套装逐级获得能力，无尽全套提供飞行、生命恢复、饱食度补充及常规伤害防护。卸下后撤销本模组授予的飞行并提供短暂缓降。
- 范围采掘遵守原版与 Fabric 保护，跳过容器和不可破坏方块，不加载区块，每次最多检查 49 格。范围攻击排除玩家与宠物；虚空和 `/kill` 仍有效。
- F3+H 高级提示框在物品 ID 正上方显示 `ENERGY <精确数值>`。服务端在加入／重载时同步公开价格，不共享个人余额和知识；`—` 表示没有可用价格。
- 保留 MIT 许可的 ProjectE／Re-Avaritia 物品、盔甲贴图和动画，附带许可与来源清单。盔甲使用原版渲染，不包含自定义宇宙着色器或翅膀。
- 更新全部十种语言及中英文文档，提供完整合成和操作指南。

要求 Minecraft 26.2、Java 25 及 README 指定的 Fabric 依赖，保留旧账户和配置。沿用 0.2.1：转化会丢弃附魔、容器内容等数据，购买返回默认物品。操作和实现差异详见 `docs/ARMORY_zh-CN.md`。
