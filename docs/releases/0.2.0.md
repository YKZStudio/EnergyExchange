# Energy Exchange 0.2.0

## English

First stable 0.2 release for **Minecraft 26.2 + Fabric / Java 25**.

### Changes since 0.1.0

- Placed and portable transmutation tables with original low stone-plate artwork and 3×3 vanilla crafting recipes.
- Private, server-authoritative item conversion, automatic learning, a learned-first searchable catalog, 64/32/16/1 purchases and configurable XP purchases.
- Positive default prices for every vanilla item ID, plus model-aware TaCZ/LRTactical integration and data-pack overrides. Recipe constraints and fractional batch conversion prevent ordinary rounding loops.
- Mod Menu settings, English default documentation with Chinese companions, and ten game locales. The mod name follows the selected language.
- Session, sequence, stack-limit, inventory and account preflight checks; existing balances and learned items are retained.

### Pinyin fixes since pre2

- Replace single-reading conversion with a bundled offline Unicode index supporting multiple Mandarin readings and simplified/traditional variants.
- Support full pinyin, initials, syllable prefixes and mixed Chinese/pinyin: `myzz`, `moyingzhenzhu`, `末影zz`, `mo影z珠` all find 末影珍珠.
- Normalize full-width letters, case, spaces and tone marks; accept `lv`, `lü`, `lǜ` and `lu:` for 绿. Both `zhongchui` and `chongchui` find 重锤.
- Bound raw input and the name cache; use dynamic matching instead of enumerating pronunciation combinations. Remove the separate TinyPinyin/Aho-Corasick dependencies.
- Keep pinyin **off by default** in Mod Menu. Literal name/ID search works while disabled. Learned/All filtering still applies; no typo correction or online lookup is performed.
- Add regression tests for the above cases and a real Chinese-client enabled/disabled search flow, alongside transaction, persistence and TaCZ tests.

Install `energyexchange-0.2.0.jar` on both client and server with matching Fabric API. Optional Mod Menu/TaCZ versions remain as documented in the README. Existing accounts and pre2 preferences are preserved. Custom gun packs and additional recipe economies remain the server owner's responsibility to price through data packs.

## 简体中文

面向 **Minecraft 26.2 + Fabric／Java 25** 的首个 0.2 正式版。

### 相比 0.1.0

- 新增放置与便携转化桌，使用原创低矮石盘外观及 3×3 原版材料配方。
- 私有、服务端权威的物品转化与自动学习，已学优先搜索目录，64／32／16／1 数量购买及可配置经验购买。
- 全原版物品默认价格，按型号区分的 TaCZ／LRTactical 适配与数据包覆盖；配方约束及分数批量结算避免普通取整套利。
- Mod Menu 设置、英文默认及中文配套文档、十个游戏区域翻译；模组名随所选语言切换。
- 校验会话、序号、堆叠上限、背包和账户，保留已有余额及知识。

### 相比 pre2 的拼音修复

- 使用内置离线 Unicode 读音索引替代单一读音转换，支持多音字及简繁体变体。
- 支持全拼、首字母、音节前缀与汉字混输：`myzz`、`moyingzhenzhu`、`末影zz`、`mo影z珠` 均可找到末影珍珠。
- 兼容全角字母、大小写、空格与声调；`lv`、`lü`、`lǜ`、`lu:` 均可匹配绿；`zhongchui` 与 `chongchui` 均可匹配重锤。
- 限制原始输入和名称缓存，用动态匹配避免多音字组合爆炸；移除独立的 TinyPinyin／Aho-Corasick 依赖。
- 拼音在 Mod Menu 中仍**默认关闭**；关闭后普通名称／ID 搜索正常。结果仍遵循已学／全部筛选，不提供错字纠正，也不联网查询。
- 新增相关回归测试及真实中文客户端拼音开关验证，并保留交易、存档与 TaCZ 测试。

双端安装 `energyexchange-0.2.0.jar` 及匹配的 Fabric API。可选 Mod Menu／TaCZ 版本见 README。已有账户及 pre2 偏好保留。额外枪包与其他配方系统的经济定价仍需服主通过数据包调整。
