# Energy Exchange 0.3.1

## English

- Show the lower-left data-discard warning only when the input has components differing from its default item/model prototype. Empty slots and ordinary items no longer show it; counts do not count as extra data.
- Expand the table input to 256 identical items with matching data, including normally unstackable tools. Click or Shift to deposit. Cursor/hotbar withdrawals, Shift transfers, drops and close/death returns respect native stack limits. Drag distribution excludes the special input slot.
- Remove direct XP purchases and their settings controls. Select Bottle o’ Enchanting and use the bottom-right 64/32/16/1 buttons to receive bottles directly in inventory, without prior learning. Buying does not grant XP.
- Default bottle price: 896 ENERGY (128 per average vanilla XP point, seven points per bottle). Normal datapack overrides can change or disable it. Inventory capacity, balance, quantity, reload revision and replay protection remain server-authoritative.
- Keep old configuration files readable; legacy xpEnabled/xpCost fields are ignored. Existing wallets and knowledge remain intact. Update both client and server.
- Update all ten locales and English/Chinese documentation; add oversized-input, safe-return, conditional-warning and bottle-purchase regression tests.

## 简体中文

- 左下角仅在输入带有默认物品／型号模板之外的数据时显示丢弃提示；空槽和普通物品不再显示，数量变化不算附加数据。
- 转化桌输入槽扩展至 256 个同物品、同数据堆叠，支持原本不可堆叠的工具。点击或 Shift 移入；光标／快捷栏取出、Shift 转移、丢弃与关闭／死亡返还遵守原生堆叠上限。拖拽分配不包含特殊输入槽。
- 删除直接购买经验及对应设置。选择「附魔之瓶」后，使用右下角 64／32／16／1 按钮直接放入玩家物品栏，无需先学习，购买不直接增加经验。
- 默认每瓶 896 ENERGY（按原版平均每瓶七点经验、每点 128 定价）。普通数据包规则仍可改价或禁用，空间、余额、数量、重载版本和重复请求校验均由服务端决定。
- 兼容读取旧配置，旧 xpEnabled／xpCost 字段不再生效，已有余额与知识保留。客户端和服务端都应更新。
- 同步十种语言与中英文文档，新增超量输入、安全返还、条件提示及附魔之瓶交易回归测试。
