# Energy Exchange 0.2.1

## English

- Default catalog order: learned items first, then exact Energy descending. Mod Menu can switch to Energy ascending or localized name order. Existing settings migrate without resetting other preferences or accounts.
- Reprice TaCZ firearms, ammo, attachments and workbenches against actual recipe costs. Apply optional-mod profiles only when the relevant mods are installed, including the cheap gunpowder recipe and fractional conversion yields.
- Support all 80 Traveler’s Backpack Fabric 26.2-11.3.2 items. Test both standalone backpack and combined TaCZ/backpack installations.
- Convert enchanted, named, damaged and data-bearing items at base value. **Enchantments, inventory contents, fluids, upgrades and other data are discarded.** Purchases return default empty items; only validated TaCZ/LR model identity is retained. Remove valuables before converting containers.
- Add an original teal/brass pixel-art icon and connect it to Fabric/Mod Menu.
- Keep all ten locales and English/Chinese documentation updated. Stable versions publish JAR + bilingual changelog; versions containing `pre` no longer create Releases.
- Add exact large-number sorting, configuration migration, decorated-item/container discard, and real optional-mod integration regressions.

Requires Minecraft 26.2, Java 25 and the Fabric dependencies documented in the README on both sides. Existing balances and learned identities are retained; prices may change. Data-pack overrides retain priority.

- 按真实配方成本调整 TaCZ 枪械、弹药、配件和工作台价格。仅在对应模组安装时启用兼容定价，包含低成本火药配方与分数转化收益。
- 适配旅行者背包 Fabric 26.2-11.3.2 的全部 80 个物品，并测试单独安装和与 TaCZ 同时安装。
- 附魔、命名、损坏及带数据物品按基础价值转化。**附魔、内部物品、液体、升级等数据均丢弃。**买回默认空物品，只保留经验证的 TaCZ／LR 型号身份；转化容器前请取出要保留的物资。

- 更新十个区域翻译及中英文文档。正式版发布 JAR 和双语日志，含 `pre` 的版本不再创建发行版。
