# Energy Exchange 0.3.4

## English

- Adds ENERGY values for all 2,053 discovered item identities in Farmer's Delight Refabricated, More Delight, Rustic Delight, Ube's Delight, BetterNether and BetterEnd on both Minecraft 26.1.2 and 26.2.
- Optional-mod prices are independent additive profiles. Any supported subset can coexist with TaCZ and Traveler's Backpack without selecting a prebuilt combination.
- Prices use vanilla crafting/smelting/stonecutting/smithing plus supported cooking, cutting, baking-mat, infusion, alloying and BCLib smithing recipes. Unresolved optional cross-mod ingredients use conservative positive fallbacks.
- Individual server data-pack `values/` and `variants/` rules still override every bundled compatibility value after `/reload`.
- No upstream mod code, textures or other assets are included. Pinned source builds and checksums are documented in `versions/price-sources.json`.

Install the JAR matching the game version on both client and server. This release does not change player balances, learned identities, worlds, recipes, UI or account schema.

## 简体中文

- 为 Minecraft 26.1.2 与 26.2 上 Farmer's Delight Refabricated（农夫乐事）、More Delight、Rustic Delight、Ube's Delight、BetterNether、BetterEnd 中发现的全部 2,053 个物品身份加入 ENERGY 数值。
- 可选模组价格改为独立叠加方案；支持的任意子集都可与 TaCZ、旅行者背包同时使用，无需选择预制组合。
- 定价使用原版合成／烧炼／切石／锻造，以及已支持的烹饪、切割、烘焙垫、灌注、合金和 BCLib 锻造配方；无法解析的可选跨模组材料采用保守的正数后备价。
- 服务端单物品 `values/` 与型号 `variants/` 数据包规则仍在 `/reload` 后覆盖全部内置兼容值。
- 不包含上游模组代码、贴图或其他素材；固定的生成来源和校验值见 `versions/price-sources.json`。

客户端与服务端必须安装对应游戏版本的 JAR。本次不改变玩家余额、已学身份、世界、配方、UI 或账户格式。
