# Energy Exchange 0.2.0-pre1 / 能量交换 0.2.0-pre1

## 简体中文

面向 Minecraft Java 26.2 + Fabric 的首次图形交易预发布版本。

- 加入可放置转化桌和便携转化桌，两种原版材料 3×3 配方，并在获得钻石时解锁配方书。
- 原版风格界面：输入格、个人目录、中英文名称/ID 搜索、分页、学习、整堆转化、单个/整组购买。
- 玩家购买经验点，默认 128 Energy/点，每次界面购买 10 点；不按等级收费。
- 为全部 1,537 个原版物品 ID 分配正数购买价格，补齐 TaCZ 枪械、弹药、配件、工作台和内置 LRTactical 型号；额外已加载枪包有基础价格后备。
- 默认价格参考普通原版配方约束；购买向上取整，分数转化收益整批向下取整，不足一点时保留输入并拒绝交易。
- 可选 Mod Menu 设置：显示未学物品、大数简写、经验开关与价格。经验规则由服务端控制，本地修改下次启动世界/服务端生效。
- 保留 0.1 账户，知识容量提高到 4,096 条（同时受序列化长度限制）；余额保持精确整数，不缩放。
- 服务端验证会话、请求序号、规则版本、距离/持有条件；重复请求拒绝重复结算。购买前整笔检查库存和余额，关闭界面返还输入。
- 数据包保留逐物品覆盖，新增逐型号规则和批量默认表；重载失败锁定物品及经验交易。
- 游戏文字、使用说明、数据包文档和开发说明均提供中英文。

安装：Java 25、Fabric Loader 0.19.5+、Fabric API 0.159.0+26.2；客户端和服务端都安装本模组。可选 Mod Menu 20.0.2。TaCZ 兼容测试使用 26.2 R3-hotfix，需其自身依赖。

限制：原版的非默认组件（命名、附魔、磨损、药水等）仍不交换；TaCZ 须使用安全标准型号，清空弹药和膛内子弹并卸下配件。新增机器/特殊配方/枪包仍需服主进行经济审查。预发布版请在备份世界中验收，详情见开发文档。

## English

The first graphical trading prerelease for Minecraft Java 26.2 + Fabric.

- Placed transmutation table and portable tablet, each crafted from vanilla ingredients in a 3×3 pattern; obtaining a diamond unlocks their recipe-book entries.
- Vanilla-style input and personal catalog with localized name/ID search, pagination, learning, whole-input conversion and single/stack purchases.
- XP-point purchases, defaulting to 128 Energy per point and ten points per UI purchase; prices are not based on levels.
- Positive purchase values for all 1,537 vanilla item IDs, plus TaCZ guns, ammunition, attachments, workbenches and bundled LRTactical models. Additional loaded gun-pack models receive base-price fallbacks.
- Default prices constrained by supported ordinary vanilla recipes. Purchase units round up; fractional conversion batches round down, with sub-one-Energy batches rejected without consumption.
- Optional Mod Menu controls for unlearned entries, compact numbers, XP enablement and price. Economy settings are server-owned; local edits apply at the next world/server start.
- Existing 0.1 accounts retained without balance scaling. Knowledge capacity increases to 4,096 keys, also bounded by serialized size.
- Server checks session identity, sequence, quote revision and table reach/possession. Replayed requests cannot settle twice. Purchases preflight the whole inventory, and closing returns input.
- Item overrides remain supported; model-specific rules and bulk defaults are added. Failed reloads lock both item and XP transactions.
- English and Simplified Chinese game text, usage, data-pack and developer documentation.

Requires Java 25, Fabric Loader 0.19.5+ and Fabric API 0.159.0+26.2, with this mod installed on both client and server. Mod Menu 20.0.2 is optional. TaCZ integration targets 26.2 R3-hotfix and requires TaCZ's own dependencies.

Limits: non-default vanilla components such as names, enchantments, damage and potion variants remain unsupported. TaCZ conversion requires safe standard models with ammunition/chamber emptied and attachments removed. Added machines, special recipes and gun packs still need an economy audit. Test this prerelease in a backed-up world; see developer documentation.
