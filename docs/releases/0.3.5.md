# Energy Exchange 0.3.5

## English

- Adds a separate Minecraft 26.3 Fabric JAR while retaining the 26.1.2 and 26.2 builds.
- 26.3 requires Fabric Loader 0.19.5+ and Fabric API 0.160.5+26.3. Optional Mod Menu integration uses 21.0.0-beta.1.
- Uses Minecraft's Escape key constant for the SDL input system. Search can still be closed with Escape.
- Adapts server-authoritative item drops to the new prediction API. Throwing the 256-item input splits it into native-size stacks.
- Adds prices for all 1,658 vanilla item IDs in 26.3, with target-specific recipe-derived salvage rates. Authored mod equipment prices and account data are preserved.
- Updates recipe-unlock advancements to the new `recipes` predicate field so worlds load correctly.
- Supplies 26.3 villager trades with integer counts for the new integer number-provider format.
- Upgrades the build wrapper to Gradle 9.6.0 and includes a reproducible target-price generator.

Install the JAR matching Minecraft on both client and server. Optional mods need their own compatible 26.3 versions; TaCZ and Traveler's Backpack integration CI remains on 26.1.2/26.2. Existing third-party price profiles do not establish compatibility with newer upstream mod builds. Back up worlds before upgrading Minecraft; do not open an upgraded world in an older game version.

## 简体中文

- 新增独立 Minecraft 26.3 Fabric JAR，保留 26.1.2 和 26.2 构建。
- 26.3 要求 Fabric Loader 0.19.5+、Fabric API 0.160.5+26.3；可选 Mod Menu 使用 21.0.0-beta.1。
- 搜索框使用原版 Escape 键常量，适配 SDL 输入系统，保持 Escape 关闭行为。
- 丢弃物品适配新版预测接口，由服务端执行；转化桌内 256 个物品按原版堆叠上限拆分落地。
- 为 26.3 全部 1,658 个原版物品 ID 提供价格，并按该版本配方生成独立回收比例。保留已维护的模组装备价格及玩家账户数据。
- 配方解锁进度改用新版 `recipes` 条件字段，修复世界加载失败。
- 为 26.3 村民交易提供整数数量资源，适配新版整数数值提供器。
- 构建工具升级至 Gradle 9.6.0，加入可复现的分版本价格生成脚本。

客户端和服务端均安装与 Minecraft 匹配的 JAR。可选模组须自行提供兼容 26.3 的版本；TaCZ、旅行者背包的兼容 CI 仍覆盖 26.1.2／26.2。已有第三方价格表不代表适配上游模组的新构建。升级 Minecraft 前备份世界，不要用旧版游戏打开升级后的世界。
