# Energy Exchange 0.3.2

## English

- Add Minecraft 26.1.2 support while retaining 26.2, with separate `energyexchange-mc26.1.2-0.3.2.jar` and `energyexchange-mc26.2-0.3.2.jar` runtime artifacts. Install only the JAR matching your game, on both sides.
- Use the tested lowest Loader for each game: 0.18.4 for 26.1.2 and 0.19.3 for 26.2. 26.2's game bootstrap cannot start with Loader 0.18.4. Keep Java 25; use Fabric API 0.155.3+26.1.2 / 0.159.0+26.2 and optional Mod Menu 18.0.1 / 20.0.2 respectively.
- Share transactions, armory, pinyin and account logic through a small version-specific client bridge. Keep all 0.3.1 behavior, including the 256 input, conditional data warning and experience bottles.
- Generate 26.1.2 prices for all 1,506 vanilla identities and its matching TaCZ/backpack resources. Preserve the 26.2 prices and datapack priority. The example pack supports formats 101.1 and 107.1.
- TaCZ R3-hotfix has its own Loader 0.19.3+ requirement. The 26.1.2 Backpack fixture's Forge Config API Port requires Loader 0.19.0+, so optional-mod integration tests use 0.19.5. Use matching game builds and Forge Config API Port 26.1.5 / 26.2.1. Backpack builds: 26.1.2-11.2.10 / 26.2-11.3.2.
- Preserve existing account/configuration formats. This release does not convert 26.2 worlds for downgrading to 26.1.2.
- Run independent build, server, client and optional-mod checks for each target before publishing both JARs and these bilingual notes together.

## 简体中文

- 新增 Minecraft 26.1.2，保留 26.2，分别提供 `energyexchange-mc26.1.2-0.3.2.jar` 和 `energyexchange-mc26.2-0.3.2.jar`。双端仅安装与游戏版本对应的一个 JAR。
- 两个游戏版本使用各自已验证的最低 Fabric Loader：26.1.2 为 0.18.4，26.2 为 0.19.3；26.2 的游戏启动程序不能在 0.18.4 上启动。继续要求 Java 25，两版本分别使用 Fabric API 0.155.3+26.1.2／0.159.0+26.2，可选 Mod Menu 18.0.1／20.0.2。
- 共用交易、装备、拼音和账户逻辑，通过少量客户端接口适配版本差异。保留 0.3.1 的 256 输入槽、条件数据警告和附魔之瓶等功能。
- 按 26.1.2 的全部 1,506 个原版物品及对应 TaCZ／背包资源生成价格，保留 26.2 原定价和数据包覆盖优先级。示例数据包兼容 101.1／107.1 格式。
- TaCZ R3-hotfix 自身要求 Loader 0.19.3+；26.1.2 背包测试所需的 Forge Config API Port 要求 Loader 0.19.0+，因此可选模组组合测试使用 0.19.5。安装对应游戏构建及 Forge Config API Port 26.1.5／26.2.1。旅行者背包构建分别为 26.1.2-11.2.10／26.2-11.3.2。
- 保留账户及配置格式，不提供将 26.2 世界降级为 26.1.2 的转换。
- 各目标分别完成构建、服务端、客户端与可选模组检查后，一并发布两个 JAR 和双语日志。
