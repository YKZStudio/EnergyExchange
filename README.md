# Energy Exchange · 能量交换

[English](README.en.md) · [中文开发说明](docs/DEVELOPMENT.zh-CN.md) · [数据包规则](docs/DATAPACKS.zh-CN.md)

面向 **Minecraft Java 26.2 + Fabric** 的独立能量交换模组。受等价交换玩法启发，未使用 ProjectE 代码或素材，也不是官方移植。

v0.1 用命令提供完整闭环：**普通物品 → 个人能量与知识 → 兑换已学物品**。暂不包含转化桌、图形界面、自动化设备或自动配方估值。

## 安装与构建

- Java 25、Minecraft 26.2、Fabric Loader 0.19.5+、Fabric API 0.159.0+26.2。
- 客户端和服务端均安装本模组与 Fabric API，以获得完整中英文显示；游戏语言选择「简体中文」或「English (US)」。也可仅服务端安装，未安装模组的客户端使用英文后备文本。
- 构建：Linux/macOS 执行 `./gradlew build`，Windows 执行 `gradlew.bat build`。成品为 `build/libs/energyexchange-0.1.0.jar`，不要安装 `-sources.jar`。
- 仓库 Actions 的成功构建提供 JAR 和测试报告。发布前请参照[验收清单](docs/DEVELOPMENT.zh-CN.md)测试副本世界。
- 当前声明兼容 `~26.2`，即 26.2 系列；后续 26.3+ 需重新构建和验证，不直接宣称无限向后兼容。

## 开始玩

所有玩家均可使用，无需 OP 或开启作弊。只允许存活的生存/冒险玩家交易。

| 命令 | 作用 |
| --- | --- |
| `/ee` 或 `/ee help` | 帮助；完整前缀为 `/energyexchange` |
| `/ee value` | 查看主手普通物品的单价 |
| `/ee burn` | 分解主手 1 个物品，并自动学会它 |
| `/ee burn 32` | 分解主手 32 个物品 |
| `/ee burn all` | 分解主手整堆，**不扫描整个背包** |
| `/ee learn` | 消耗主手 1 个样本，仅学习，不产生能量；已学物品不重复消耗 |
| `/ee balance` | 查询精确能量余额 |
| `/ee list [页码]` | 分页查看已学物品，每页 12 项 |
| `/ee buy minecraft:cobblestone 16` | 兑换 16 个已学物品；省略数量为 1，可用 Tab 补全已学 ID |

例：主手拿 64 个圆石，执行 `/ee burn all` 获得 64 能量并学会圆石；执行 `/ee buy minecraft:cobblestone 16` 获得 16 个圆石，余额变为 48。

## 边界与安全

- 使用 `BigInteger`（任意精度整数），范围为 `0` 至 `10^128−1`；不使用浮点数。超限整笔拒绝，不截断、不环绕。
- 服务端计算价格、余额、知识、手持物品和背包容量。没有接受客户端余额或物品堆的自定义网络包。
- 分解和学习仅接受与该物品默认数据组件完全一致的物品；命名、附魔、磨损、书本内容、药水变体、容器内容、自定义数据等均不支持。兑换只产生默认物品。
- 数据包中没有价格或被禁用的物品不可分解、学习或兑换。默认仅给 20 种基础资源定价，不自动推导配方；整合包作者仍需审查跨模组合成/机器配方套利。
- 一次兑换数量为 1–2304，必须全部放入 36 格主背包及快捷栏。先模拟堆叠，再一次执行；容量不足不扣款，不丢落地物品。不向盔甲槽、副手或容器塞物品；交易前需关闭容器界面。
- 能量和已学物品存于玩家数据附加项 `energyexchange:account`，随玩家存档保存，死亡保留、跨维度保留、重新登录/正常重启保留；无全服共享钱包。
- 最多学习 1024 种物品，序列化账户最长 60,000 字符。损坏或不支持的账户版本锁定交易并保留原始数据，不静默重置。移除模组前备份世界，未加载本模组时保存可能丢失附加数据。
- 重载期间暂停交易；重载失败后维持锁定，修复后成功 `/reload` 才恢复。规则删除后知识保留，但不能兑换；恢复规则后可再次兑换。
- 遵循 Minecraft 正常存档时机，不承诺断电时每笔交易持久化；异常崩溃可能回滚到上次玩家存档。管理员/其他模组直接改存档、物品或切换创造模式不属于可防御的信任边界。
