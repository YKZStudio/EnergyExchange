# 能量交换

[English](README.md) · [更新日志](docs/releases/0.3.5.md) · [数据包](docs/DATAPACKS_zh-CN.md) · [开发与验收](docs/DEVELOPMENT_zh-CN.md)

面向 **Minecraft Java 26.1.2 / 26.2 / 26.3 + Fabric** 的独立能量交换模组。受等价交换玩法启发，未使用 ProjectE 代码或素材，也不是官方移植。

**0.3.5 新增 Minecraft 26.3 适配，为 26.1.2、26.2、26.3 提供独立 JAR。**

## 安装

要求 Java 25。双端安装对应游戏版本的运行 JAR，不安装源码 JAR，也不同时安装多个目标的 JAR。

| Minecraft | 运行 JAR | Fabric API 最低版本 | 可选 Mod Menu |
| --- | --- | --- | --- |
| 26.1.2 | `energyexchange-mc26.1.2-0.3.5.jar` · Loader 0.18.4+ | 0.155.3+26.1.2 | 18.0.1 |
| 26.2 | `energyexchange-mc26.2-0.3.5.jar` · Loader 0.19.3+ | 0.159.0+26.2 | 20.0.2 |
| 26.3 | `energyexchange-mc26.3-0.3.5.jar` · Loader 0.19.5+ | 0.160.5+26.3 | 21.0.0-beta.1（可选） |

26.3 使用 SDL 输入系统及独立原版价格、村民交易资源。可选兼容模组仍需各自提供 26.3 构建；现有 TaCZ／背包兼容测试只覆盖 26.1.2 和 26.2。Mod Menu 目前提供面向 26.3 候选版的测试版本，客户端 CI 将验证其兼容性。

TaCZ R3-hotfix 有 26.1.2 和 26.2 的构建，但自身要求 Loader **0.19.3+**（兼容测试使用 0.19.5）。26.1.2 使用 Forge Config API Port 26.1.5，26.2 使用 26.2.1。双端 TaCZ 和枪包需匹配。不要将 26.2 世界直接降级到 26.1.2；此次提供低版本游戏构建，不负责世界降级转换。

保留十种区域语言，游戏内名称跟随所选语言；Mod Menu 使用其名称翻译设置。

- 0.1 玩家账户直接保留，余额不缩放、知识不重置。升级前备份世界；0.2 的新物品和变体知识不支持直接降级到 0.1。

## 合成与使用

两种物品均在工作台使用 **3×3 原版材料配方**，无需 OP 或作弊。

| 转化桌 | 第 1 列 | 第 2 列 | 第 3 列 |
| --- | --- | --- | --- |
| 第 1 行 | 黑曜石 | 钻石 | 黑曜石 |
| 第 2 行 | 红石粉 | 钻石 | 红石粉 |
| 第 3 行 | 黑曜石 | 钻石 | 黑曜石 |

| 便携转化桌 | 第 1 列 | 第 2 列 | 第 3 列 |
| --- | --- | --- | --- |
| 第 1 行 | 黑曜石 | 金锭 | 黑曜石 |
| 第 2 行 | 金锭 | 钻石 | 金锭 |
| 第 3 行 | 黑曜石 | 金锭 | 黑曜石 |

放置转化桌后右键，或在主手/副手使用便携转化桌。界面左侧是输入格，右侧是个人交易目录，下方是背包。

1. 把普通物品放入输入格，点「全部转化」：整堆变为 能量，并自动学会该物品。
2. 默认仅显示已学物品；可以切换「全部物品」，已学的仍排在前面。默认按能量精确数值从高到低排序，Mod Menu 可改为从低到高或按名称。已移除单独的学习按钮。
3. 按本地化名称或 ID 搜索，选中后使用「购买：64个／32个／16个／1个」。超过堆叠上限或余额不足的按钮不可用；末影珍珠只能选择 16 或 1，不可堆叠物品只能选 1。灰色表示未学会，悬浮提示显示精确价格和收益。
4. 点击「附魔之瓶」，再使用右下角 64／32／16／1 数量按钮购买，直接放入玩家物品栏。无需预先学习，默认每瓶 **896 ENERGY**，数据包可改价或禁用。投掷后按原版规则获得经验，不直接增加经验点。
5. 关闭界面自动返还输入格。桌子本身没有公共储物空间，其他玩家不能访问你的钱包或输入。

仅存活的生存/冒险玩家可交易。放置版要求仍在桌子 8 格范围内；便携版打开期间锁定所在背包槽，切换手持物品或失去桌子后交易失效。

村民也会通过原版交易界面出售能量交换物品：图书管理员出售转化桌和便携转化桌，牧师出售材料，工具匠和武器匠出售工具，盔甲匠出售盔甲。新增内容加入原有职业等级的交易池，不替换原版交易。暗物质、红物质交易需要后期原版材料；无尽系列交易每位村民仅可完成一次，并要求 64 个下界合金块和 1 个下界之星。新生成的村民，以及安装后新提升等级的村民，会使用当前数据包规则。

## 定价与兼容

- 为 **26.1.2 的全部 1,506 个／26.2 的全部 1,537 个／26.3 的全部 1,658 个原版物品 ID** 分配正数购买价格；包含非生存物品，但它们同样需要先获得样本并学习，不会直接解锁。
- TaCZ 枪型、弹种、配件、工作台和内置 LRTactical 物品按具体型号区分。额外枪包的已加载型号使用相应基础物品的后备价格，可用数据包逐型号覆盖。
- 安装 Farmer's Delight Refabricated（农夫乐事）、More Delight、Rustic Delight、Ube's Delight、BetterNether 或 BetterEnd 时，会叠加对应的配方约束价格；每个目标版本共覆盖 **2,053 个可选物品 ID**。它们可任意组合，并可与 TaCZ／旅行者背包同时使用；服务端单物品数据包规则仍拥有最终优先级。
- 默认值由 `tools/generate_values.py` 生成，包含原版普通合成、烧炼、切石及锻造配方约束。购买单价向上取整，非整数转化收益整批向下取整；不足 1 能量 时拒绝并返还原输入。例如半块材料不会凭空变成一整点能量。
- 这是可配置的初始平衡方案，不是所有模组机器、交易、特殊合成和枪包的经济证明。服主应审查整合包新增配方，并按需覆盖或禁用规则。存量 0.1 价格可能因配方约束调整，个人余额不改变。
- **数据会被丢弃：**命名、附魔、磨损及带内容的物品均只按基础身份计价。转化会丢弃附魔、名称、内容物、液体、升级等附加数据，容器只计算外壳价值，内部物品不额外计价。购买返回默认状态，绝不复制样本的数据。
- TaCZ 保留经验证的枪型、弹种和配件型号身份以区分价格；装填弹药、附加配件、外观等其他数据丢弃，购买默认空枪／标准型号。未知型号仍会拒绝。

## 设置与数据包

Mod Menu → 能量交换 → 设置：显示未学物品、简写大数、实验性拼音搜索、物品排序。

拼音搜索**默认关闭**。开启后，`moyingzhenzhu`、`myzz`、`moyzz` 都可找到「末影珍珠」，支持大小写、空格、声调、全角字母、音节前缀混拼及汉字混输（`末影zz`、`mo影z珠`）。绿色羊毛可用 `lv`／`lü`／`lǜ`／`lu:` 搜索；重锤可用 `zhongchui` 或 `chongchui` 搜索。离线可用，无需 REI。结果仍受「已学／全部」筛选限制，并使用当前语言下的名称；不提供错字纠正。

旧 pre1 的四项配置自动迁移：拼音关闭，初始目录改为仅已学；保留大数显示偏好；旧经验字段仍可读取，但自 0.3.1 起不再生效。余额和知识不会重置。

显示、拼音和排序是客户端偏好。物品及附魔之瓶价格由服务端数据包决定；旧 `xpEnabled`／`xpCost` 字段只为兼容旧配置保留，已经没有经验购买设置。大数悬浮提示和 `/ee balance` 始终显示精确整数。

[数据包文档](docs/DATAPACKS_zh-CN.md)包括物品禁用、价格覆盖、TaCZ 变体路径及 `/reload` 行为。

## 命令与保护

仍支持 `/ee help`、`value`、`balance`、`list [页码]`、`learn`、`burn [数量|all]`、`buy <物品ID> [数量]`。例如 `/ee buy tacz:modern_kinetic_gun#tacz:ak47 1`。在转化界面中，转化/学习操作针对输入格；关闭界面时针对主手。其他容器打开时禁止交易。

- 能量 为 `0` 至 `10^128−1` 的精确整数；溢出整笔拒绝。
- 服务端检查当前菜单、会话标识、请求序号、规则版本、距离、模式、知识、价格与库存；客户端不提交余额或物品堆。过期报价要求刷新，重复请求不会重复结算。
- 命令购买 1–2304 个物品前模拟全部背包插入，空间不足不扣费、不掉落、不部分发货。不写入盔甲或副手。
- 账户保留死亡/重生、换维度、正常重启。最多 4,096 条知识，序列化长度上限 60,000 字符；全原版知识可以保存。损坏/未来格式锁定交易并保留原数据。
- 数据包重载期间暂停交易；失败持续锁定，修正并成功 `/reload` 后恢复。被禁用物品的已有知识保留。
- 遵循 Minecraft 正常存档时机；断电或进程异常退出可能回滚到上次存档。管理员和其他模组对玩家数据的直接修改不在本模组的事务控制范围内。

## 构建与发行

`./gradlew build -Pminecraft_version=26.1.2` 或 `./gradlew build -Pminecraft_version=26.2` 运行编译、单元测试和专服游戏测试；`xvfb-run -a ./gradlew runClientGameTest -Pminecraft_version=26.1.2`（也可选择 `26.2`）在 Linux 验证客户端交易界面。26.3 无显示器测试使用 `SDL_VIDEO_DRIVER=offscreen LIBGL_ALWAYS_SOFTWARE=1 ./gradlew runClientGameTest -Pminecraft_version=26.3`。Windows 使用 `gradlew.bat`。

每个正式版本都发布 GitHub Release，包含运行 JAR 与双语更新日志；已有资产不静默替换。参见 [0.1.0 正式版](https://github.com/YKZStudio/EnergyExchange/releases/tag/v0.1.0)。

## 0.3.1 兼容与定价

可选安装旅行者背包 **Fabric 26.1.2-11.2.10／26.2-11.3.2**，覆盖全部 80 个注册物品。装有物品、染色或升级后的背包仍按注册物品基础价值计价，买回空的默认等级背包。请先取出需要保留的内容再转化。

服务端根据安装情况选择原版、TaCZ、背包或两者共同的配方定价方案，修复 TaCZ 低成本火药合成循环，并按实际可解析配方重新计算枪械、弹药、配件和背包价值。分数收益仅在整批结算时向下取整，数据包单物品／型号覆盖仍优先。详见[定价说明](docs/PRICING_zh-CN.md)。

只有正式版创建包含 JAR 和双语日志的 GitHub 发行版；含 `pre` 的版本仍进行 CI 构建，但不创建发行版。

## 0.3 装备与高级提示框

新增暗物质、红物质、无尽三阶装备与工具，共 32 个物品。全部使用原版 3×3 工作台，包含范围采掘、范围攻击和无尽套装飞行。按 F3+H 后在物品 ID 上方显示服务端精确 ENERGY 单价。查看[完整合成与操作](docs/ARMORY_zh-CN.md)。

## 0.3.1 输入槽

单个输入槽可堆叠 **256 个同物品、同数据**的物品，支持多次点击或 Shift 快速移入，包括原本不可堆叠的工具。左键取出最多一个原生堆叠，右键取出半数但不超过原生上限，Shift 取出尽量移入物品栏。数字键换位、丢弃、关闭界面／死亡返还均拆回原生堆叠；物品栏满时按原版规则掉落。拖拽分配不包含这个特殊输入槽。

左下角仅在输入具有默认模板之外的数据时显示丢弃提示；空槽和普通物品不显示。有效 TaCZ 型号按该型号的默认模板比较。双方都应更新至对应 Minecraft 的 0.3.2。
